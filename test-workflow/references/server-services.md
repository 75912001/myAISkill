# Server 服务测试引用

在 `D:\src\github.com\server` 中工作，或用户提到 server 里的服务时，使用此引用。

选择测试命令前，先读取对应服务的 `TEST.md`：

- Cache：`D:\src\github.com\server\cache\TEST.md`
- Gateway：`D:\src\github.com\server\gateway\TEST.md`
- Online：`D:\src\github.com\server\online\TEST.md`
- Login：`D:\src\github.com\server\login\TEST.md`

如果改动跨服务，读取所有受影响服务的测试指南，并运行其中覆盖范围最大的依赖检查。
