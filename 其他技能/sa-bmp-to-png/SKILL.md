# sa.bmp转换png

## 执行流程

1. 获取用户明确指定的目标文件夹。未提供路径时先询问, 不使用默认目录。
2. 明确告知用户该操作会递归处理子文件夹, 并在每张 PNG 成功生成和校验后永久移除对应 BMP。
3. 使用 Git Bash 运行 `scripts/convert_bmp_to_png.py`:

   ```bash
   python "<skill目录>/scripts/convert_bmp_to_png.py" "<目标文件夹>"
   ```

4. 若缺少 Pillow, 直接报告依赖错误。安装依赖会联网并影响本机 Python 环境, 必须先获得用户确认, 不得由脚本自动安装。
5. 检查脚本退出码和汇总结果。退出码非 0 时, 清楚列出失败原因和影响范围, 不得掩饰失败或覆盖已有 PNG。
6. 成功后确认报告中的剩余 BMP 数量为 0, 再向用户汇报转换和移除数量。

## 安全约束

- 只处理扩展名为 `.bmp` 的普通文件, 大小写不敏感。
- 不跟随目录符号链接, 不处理目标文件夹之外的内容。
- 默认输出到源 BMP 所在目录, 使用相同文件名和 `.png` 扩展名。
- 目标 PNG 已存在时, 先生成并校验临时 PNG。两者 MD5 相同则保留现有 PNG 并移除源 BMP; MD5 不同则将新 PNG 保存到同级 `new` 目录。
- `new` 目录中的同名 PNG 已存在时, MD5 相同则复用并移除源 BMP; MD5 不同则该文件处理失败并保留源 BMP, 不覆盖任何 PNG。
- 多个 BMP 映射到同一输出时, 在转换前整体终止。
- 将精确纯黑像素 `(0, 0, 0)` 的透明度设为 0, 其他像素保持原透明度。
- 每张 PNG 写入临时文件后, 必须校验格式和尺寸, 再发布为最终 PNG 并删除对应 BMP。
- 单张文件失败时保留该 BMP, 继续处理其他文件, 最终返回失败并报告失败数量。
